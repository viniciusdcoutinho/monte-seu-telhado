# Monte seu Telhado

Protótipo mobile do configurador gamificado de telhados da Loja Kingspan Isoeste (lojakingspan.com/br).

- Página única: `index.html` (HTML + CSS + JS, sem build).
- Estúdio 3D (aberto pelos cards da etapa Formato): usa o `three.min.js` (three.js r159, licença MIT) que fica ao lado do `index.html`. Se o arquivo faltar, a página baixa a mesma versão do jsDelivr.
- Deploy: Vercel, Framework Preset **Other**, sem comando de build.
- Preços, prazos e parcelamento são **ilustrativos**.
