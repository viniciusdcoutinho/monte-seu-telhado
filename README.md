# Monte seu Telhado

Protótipo mobile do configurador gamificado de telhados da Loja Kingspan Isoeste (lojakingspan.com/br).

- Arquivo único: `index.html` (HTML + CSS + JS, sem build).
- Deploy: Vercel, Framework Preset **Other**, sem comando de build.
- Preços, prazos e parcelamento são **ilustrativos**.
